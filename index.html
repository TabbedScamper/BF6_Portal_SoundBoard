How these sounds are sourced

V2.00 has two libraries. Portal Sounds contains the 937 sounds Portal's mod.PlaySound can play. 934 use real game audio with all 5,950 authored variants. The other three keep their original recordings and are marked recorded.

The Portal list comes from RuntimeSpawn_Common in Portal SDK v?: ? sounds across ? categories. SFX_VOModule is excluded because it is a silent carrier for PlayVO.

Announcer cards use recordings of PlayVO lines, grouped by event and objective flag. Some events played the wrong line or stayed silent during testing. Their warnings and silent placeholders remain.

Game Library contains every sound in the game: 287,216 clips across 14,637 sounds, about 195 hours of audio. Categories follow the game's own folders. Clips stream from Cloudflare R2. Description and name search uses the whole library index. Measurement filters apply to the loaded page.

Each new play cycles to another variant when available. Portal cards have a Try another variant button. Game Library uses the same variant control. Card and dock downloads save the current variant; Portal category and full-library ZIPs include every variant.

Game loops keep their full authored sample range and repeat through the Web Audio API. Recorded loops keep their existing matched loop points. The dock controls playback, seeking, volume and looping.

RADAR opens the spatial panel. For 3D sounds, drag the source around the listener and set the range, amplitude and scope. The panel generates TypeScript to spawn the sound and call mod.PlaySound. Coordinates are relative to the listener; add the player's world position in your script. 2D sounds play without positional attenuation. The preview's falloff is approximate.

Crash, silent and unreliable warnings describe observed Portal behaviour. An available game-file preview does not remove those warnings.

Credits

Sounds: all audio is from Battlefield 6 / Portal (© EA & DICE), used for reference and modding. Portal SFX and Game Library clips come from game files, except the three retained SFX recordings and announcer PlayVO recordings.

Game audio: lossless decoded assets from the BF6 Modding SDK audio export; all authored variants supplied by that export are included.
